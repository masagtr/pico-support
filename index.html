PICO CONTROL / SUPPORT

PICOの使い方と
サポート

接続から通知設定、困ったときの確認まで。

PICO CONTROLは、PICO本体の通知LEDを設定する無料のiPhoneアプリです。対応するPICO本体が別途必要です。

02 / GET CONNECTED

はじめての接続

  1. PICOを近くに置く

    充電したPICOをiPhoneの近くに置きます。他のBluetooth操作アプリでPICOを操作している場合は、その操作を終了してください。

  2. アプリで本体を選ぶ

    PICO CONTROLを開き、Bluetoothの使用を許可します。「ANNA接続確認モード」がオフになっていることを確認し、「近くのPICOを探す」から自分の本体を選びます。

  3. ペアリングと通知共有を許可する

    iPhoneに確認画面が表示されたら許可します。登録済みの本体では、確認画面が表示されない場合があります。

  4. 「操作できます」を確認する

    接続と準備が完了すると、通知設定を変更できます。まだ準備中の場合は少し待ち、「本体の状態」から「状態を読む」を押してください。

03 / MAKE IT YOURS

通知の色と回数を設定する

「アプリ別の通知設定」で、通知ごとの色と点滅方法を設定します。

色と回数を選び、「設定」を押すと本体に保存します。通常時は、左右のLEDが赤→青→緑の順に速く3回点滅して、設定を受け取ったことをお知らせします。充電・低電圧の表示中は、確認点滅を省略する場合があります。

白は赤・青・緑のLEDを同時に点灯させた色です。通知の到達や分類、解除のタイミングは、iPhoneの設定、通知元アプリ、接続状態により異なります。

04 / TROUBLESHOOTING

困ったときの確認

「接続済み」なのに設定ボタンが押せません

Bluetoothの接続後、本体の認証と通知の準備が必要です。「ANNA接続確認モード」をオフにし、「本体の状態」→「iPhoneの認証・通信準備を確認」を実行してください。

確認画面が出た場合は許可し、約10秒待ってから「状態を読む」を押します。改善しない場合は、表示された状態と本体の種類をお問い合わせ窓口へお知らせください。

PICOに通知が表示されません
  1. 通知元アプリの通知が、iPhone自体に届いているか確認します。
  2. iPhoneのBluetooth設定でPICOへの通知共有を確認します。
  3. 通知元アプリの通知設定、通知センターへの表示、プレビュー設定、集中モードを確認します。
  4. 充電中・低電圧警告中でないか、アプリのPOWER表示を確認します。

充電・低電圧警告の表示は、通知LEDより優先されます。iPhoneに届かない通知を、PICOだけで発生させることはできません。

プレビューを「常に」に変更すると、ロック画面にも通知内容が表示されることがあります。内容の見え方も確認して設定してください。

既読にしたのに点滅が残っています

PICOは、iPhoneから受け取る通知の削除情報に応じて表示を解除します。通知元アプリでの既読操作と、iPhoneの通知削除は同じ条件とは限りません。

通知センターと接続状態を確認してください。圏外などで解除情報を受け取れなかった場合を含め、表示が残るときはPICO本体のボタンを短押しして解除できます。

LINE通話が電話用の色で点滅します

iPhoneからLINE通話が電話の通知として渡された場合は、電話の設定で表示されます。PICOが使える分類情報は、iOSと通知元アプリから届く情報によって異なります。

POWERでバッテリー残量が分かりますか？

POWERは「通常」「充電中」「充電完了」「低電圧警告」などの状態を示します。電池残量の割合や残り使用時間ではありません。「通常」も満充電を意味しません。

表示は最後に読み取った値です。「本体の状態」→「状態を読む」で更新してください。電圧が表示される場合も、測定箇所に応じた概算値であり、電池端子そのものの電圧や正確な残量を示すものではありません。

自動で再接続されません

「登録済みPICOに自動再接続」がオンか確認してください。アプリで「切断」を押した場合は、次に手動で接続するまで自動再接続を停止します。

PICOを近づけ、「前回のPICOに再接続」または「近くのPICOを探す」から接続してください。アプリを強制終了した場合は、開き直してください。

通信ログは自動で送信されますか？

自動では送信されません。「通信ログ」→「保存・共有」を選び、iPhoneの共有画面で保存先・送信先を選んだ場合に、その相手やサービスへ渡されます。お問い合わせへのログ添付は任意です。

詳しくはプライバシーポリシー「通信ログの保存・共有」をご確認ください。
